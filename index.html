Manual Setup

1
Add the repository source
$ echo "deb [arch=aarch64] https://uncode-ide.github.io/repo uncode main" \ > $PREFIX/etc/apt/sources.list.d/uncode.list
2
Install the GPG signing key
$ curl -fsSL https://uncode-ide.github.io/repo/assets/uncode.gpg \ -o $PREFIX/etc/apt/trusted.gpg.d/uncode.gpg
3
Update and install packages
$ pkg update $ pkg install <package-name>
